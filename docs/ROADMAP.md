## مقترحات لاحقة (بطلب صاحب المشروع فقط)

1. **توقيع رقمي** لبرنامج ويندوز يزيل تحذير SmartScreen. يحتاج شهادة مدفوعة.
2. **النشر عبر winget وScoop** مثل برامج FastKiwi الأخرى.
3. **تحديث تلقائي** داخل برنامج ويندوز.
4. **قوالب طباعة** للشيك والفاتورة وسند القبض، تُصدَّر PDF.
5. **نشر المكتبة على npm** للمطورين.
6. **إضافة رسمية لـ Excel وGoogle Sheets** (Office Add-in).
7. **لغات إضافية:** التركية، والفارسية، والأردية، والإسبانية، حسب الطلب. كل لغة = وحدة قواعد + أسماء الوحدات + حالات ذهبية.
8. **كتابة الإنجليزية بأحرف كبيرة** (ONE THOUSAND…) كخيار للشيكات.
9. **مراجعة لغوية متخصصة** للبنود المحسومة حسب العرف المحاسبي (المواصفة §16 و§17).
10. **إعادة تسمية المستودع** من `tafket` إلى `InstaWords`، من إعدادات GitHub.

## English summary

v1.1.0 (done): rename to **InstaWords**; multi-language engine (Arabic + English + French, one module per language, unit names under `i18n`); language picker; UI polish; offline Windows app (Tauri, NSIS, built by GitHub Actions, published to Releases); Excel language parameter with exact parity; docs and deployment.

Later, on request: code signing, winget/Scoop, auto-update, print templates (cheque/invoice/receipt → PDF), npm package, Office/Sheets add-in, more languages (Turkish, Persian, Urdu, Spanish…), upper-case English option, specialist linguistic review, repository rename.
