InstaWords for Excel

Free Excel add-in · No internet · No subscription

Amounts in words inside Excel, on your computer and offline

Install one add-in in Excel once, and the TAFQIT function is available in every workbook you open. It runs locally, with no connection, and gives exactly the same English, Arabic or French text as InstaWords in the browser.

Download the InstaWords.xlam add-in How to install

One file with the function and every currency and unit · Excel for Windows. For macOS or a single workbook: Tafqit.bas (how).

Install the add-in once

  1. Save InstaWords.xlam in a folder you will keep, such as an InstaWords folder in Documents. Excel loads the add-in from there every time.
  2. Unblock it first: right-click the file → Properties → at the bottom of the General tab tick Unblock → OK. Windows marks every file downloaded from the internet, and Excel blocks the macros in marked files, so the function will not work without this step. (If the option is not there, the file is not blocked.)
  3. In Excel: File → Options → Add-ins → Manage: Excel Add-ins → Go… → Browse… → pick InstaWords.xlam → OK.
  4. Make sure “InstaWords” is ticked in the list, then OK. Now type =TAFQIT(A1, "USD", , , , , "en") in any workbook; there is no need to save it as .xlsm.

The add-in is built to the Excel file-format specifications and checked automatically by reading the produced file back, but it has not yet been tried in a real Excel. If it does not work for you, use the Tafqit.bas method and tell us through “Report a problem” at the bottom of the page.

Usage

Type this formula in any cell, where A1 is the cell with the amount:

=TAFQIT(A1, "USD", "", "", "Only", "", "en")

If A1 holds 2500, the result is:

Two Thousand Five Hundred US Dollars Only

The arguments after the number are optional, and "en" (the seventh) selects English; =TAFQIT(B2, "SAR", , , , , "en") gives “One Thousand Two Hundred Fifty Saudi Riyals and Seventy-Five Halalas” for 1250.75. Leave the language out for Arabic, or use "fr" for French.

If a security notice appears: the Trust Center

If Excel shows a security notice about the add-in when it starts, or the function returns #NAME?, the safest fix is to make the add-in's folder a Trusted Location:

  1. File → Options → Trust Center → Trust Center Settings…
  2. Trusted Locations → Add new location… → choose the folder that holds InstaWords.xlam → OK.
  3. Close Excel and open it again.

Do not choose “Enable all macros” under Macro Settings: it lets any file run programs on your computer. The default (“Disable all macros with notification”) plus a Trusted Location is enough.

Alternative: the Tafqit.bas module in one workbook

For Excel on macOS, or if you want the function inside a particular workbook that you send to others. Download Tafqit.bas, then:

  1. Open the workbook in Excel, then press Alt + F11 to open the Visual Basic editor (on a Mac: Option + F11, or Tools → Macro → Visual Basic Editor).
  2. In the File menu choose Import File… and select the Tafqit.bas file you downloaded.
  3. Close the editor and save the workbook as an Excel Macro-Enabled Workbook (.xlsm) so the function stays with it.

If a security warning appears when you open the workbook later, choose “Enable Content”. If Excel blocks macros in a file downloaded from the internet, open the file's Properties in Windows and tick “Unblock”.

Arguments

#ArgumentDescription
1NumberA cell or a value. Text works too, with Western or Arabic-Indic digits.
2UnitThe currency code such as "USD" or "SAR", a symbol such as "$" or "€", or the unit's id such as "kilogram" (Arabic names work too). Leave it empty for a plain number.
3HundredsFormArabic only: how “hundred” is spelled. Leave it empty in English and French.
4PrefixOptional text before the amount, such as “The sum of”.
5SuffixOptional text after the amount, such as “Only”.
6Decimals"round" (the default) to round extra decimals half up to the currency's subunit, or "error" to show an error.
7Language"en" for English, "fr" for French, or "ar" (the default, also when empty) for Arabic, in any letter case.

When the number is not valid, the function returns a message explaining why instead of the text; these messages are in Arabic in every language. =TAFQIT_CLEAN(A1) returns the cleaned number, such as 123.45 for the input ١٢٣٫٤٥.

For developers: a JavaScript library

The core that runs this site is a small library with no dependencies, for the browser and Node.js. The lib/ folder of this site is a ready-made copy, and you can build it from the repository with npm run build.

import { tafqit, tryTafqit, createTafqit } from "./lib/index.js";

tafqit("1250.75", { unit: "SAR", language: "en" });
// "One Thousand Two Hundred Fifty Saudi Riyals and Seventy-Five Halalas"

tafqit("2500", { unit: "USD", language: "en", suffix: "Only" });
// "Two Thousand Five Hundred US Dollars Only"

const r = tryTafqit("abc", { unit: "SAR", language: "en" }); // never throws
if (!r.ok) console.log(r.error.code, r.error.message);

// Custom units: edit units.json, then build an engine from it
const engine = createTafqit(await (await fetch("units.json")).json());
engine.tafqit("300", { unit: "EUR", language: "fr" });

Options: unit, language ("ar", the default, "en" or "fr"), decimals ("round" or "error"), prefix, suffix and, for Arabic, hundredsForm. Error codes such as INVALID_FORMAT are stable; the messages are in Arabic. Full details are in the project repository on GitHub.
